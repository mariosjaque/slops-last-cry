Slop's Last Cry

Slop's Last Cry plays your own copy of Banshee's Last Cry (iOS, 32-bit, Aksys). It contains nothing from the game: this setup reads your .ipa file once and converts it.

1. Your game file
2. This folder Choose the Slop's Last Cry folder (the one with index.html and setup.html). The converted files are written there.
This browser can't run the setup. Use Google Chrome or Microsoft Edge (version 103 or newer).
